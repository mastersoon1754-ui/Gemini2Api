## How these numbers were measured

- **Method**: streaming `/v1/chat/completions` requests per model through the proxy.
- **Prompt**: "Write a detailed three-paragraph explanation of how the internet works, covering DNS, TCP/IP, HTTP and routing. Be thorough."
- **Runs per model**: 1 (averaged)
- **First byte**: time until the first content delta arrived (includes model think time for thinking models).
- **Total time**: request start → `[DONE]`.
- **Tokens**: estimated as `chars ÷ 4` — the same convention this proxy uses in its `usage` fields. Not exact tokenizer output, but consistent.
- **Tokens/s (stream)**: tokens ÷ (total − first-byte) — actual generation speed once output starts flowing.
- **Tokens/s (overall)**: tokens ÷ total — what you effectively get including the wait.
- **Conditions**: anonymous (no cookie), streaming. Pro models (`3.1-pro*`) route to Flash without a Gemini Advanced cookie.

## Model details

### `gemini-3.7-flash`
- **What**: the newest all-around Flash model.
- **Best for**: everyday agent work, coding, quick answers with good quality.
- **Measured**: first byte ~2.0 s, total ~12.6 s, ~45.8 tok/s streaming.
- **Notes**: the current top pick if you want the latest backend.

### `gemini-3.6-flash`
- **What**: the all-around Flash model (previous default).
- **Best for**: the safe default — fast, capable, handles tools and agents well.
- **Measured**: first byte ~1.9 s, total ~13.8 s, ~48.8 tok/s streaming.
- **Notes**: fastest first-byte of the flash family; good balance.

### `gemini-3.5-flash`
- **What**: alias that routes to the gemini-3.6-flash backend.
- **Best for**: compatibility with old configs/scripts that hardcode the name.
- **Measured**: first byte ~1.7 s, total ~13.1 s, ~42.2 tok/s streaming.
- **Notes**: same backend as 3.6, so prefer gemini-3.6-flash for new configs.

### `gemini-3.5-flash-thinking`
- **What**: deep thinking mode; longest output of the family (~20k chars).
- **Best for**: hard problems — debugging, architecture, math, long codegen.
- **Measured**: first byte ~4.4 s, total ~16.3 s, ~52.1 tok/s streaming.
- **Notes**: pays the extra wait for quality; ideal for tough agent tasks.

### `gemini-3.1-pro`
- **What**: Pro-tier model.
- **Best for**: advanced math & code — requires a Gemini Advanced cookie for real Pro routing.
- **Measured**: first byte ~3.8 s, total ~15.8 s, ~49.2 tok/s streaming.
- **Notes**: without a cookie it silently falls back to Flash (see README).

### `gemini-3.1-pro-enhanced`
- **What**: Pro with an experimental output-enhancement flag.
- **Best for**: Pro users who want maximum output quality over speed.
- **Measured**: first byte ~1.4 s, total ~11.7 s, ~34.1 tok/s streaming.
- **Notes**: also needs the Pro cookie; the boost is experimental.

### `gemini-auto`
- **What**: lets Gemini pick the model per request.
- **Best for**: when you don't want to choose — trade-off handled upstream.
- **Measured**: first byte ~5.5 s, total ~16.8 s, ~51.6 tok/s streaming.
- **Notes**: quality/price decision is made by Gemini.

### `gemini-3.5-flash-thinking-lite`
- **What**: adaptive thinking depth.
- **Best for**: a middle ground — smarter than plain flash, faster than full thinking.
- **Measured**: first byte ~2.0 s, total ~12.5 s, ~42.0 tok/s streaming.
- **Notes**: good 'thinking without the full wait' option.

### `gemini-flash-lite`
- **What**: lightweight model.
- **Best for**: high-volume simple Q&A, titles, summarization, cheap/fast loops.
- **Measured**: first byte ~1.8 s, total ~12.7 s, ~46.0 tok/s streaming.
- **Notes**: the recommended small_model in OpenCode configs.
